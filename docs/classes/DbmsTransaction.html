    Class DbmsTransactionAbstract

    A transaction that announces begin, commit, and abort.

    💡 Constructing it sends transaction:begin.

    Example

    import { DbmsTransaction } from "@itsaorg/dbms-base";

    class Unit extends DbmsTransaction {
      constructor() {
        super("txn-1");
      }
    }

    new Unit().commit();
